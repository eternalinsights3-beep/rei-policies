# Privacy Policy — REI VM ASEC
Last updated: October 4, 2026

REI VM ASEC is a personal application used only by its owner, Recurring Eternal Insights, with his own Google accounts. It is not offered to the public.

**Data accessed.** With the owner's consent, the app reads, searches and drafts email in the owner's Gmail accounts through the Gmail API.

**Use.** Data is used only to carry out tasks the owner requests. It is processed on the owner's private server and is not sold, shared with third parties, or used for advertising.

**Storage and security.** Access tokens are stored encrypted on a private server reachable only through the owner's private network. The owner can revoke access at any time at https://myaccount.google.com/connections.

**Google API Services.** Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
